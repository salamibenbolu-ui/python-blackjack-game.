# Python Blackjack Game

A command-line Blackjack game built with Python. This project simulates a simplified version of the classic Blackjack card game, allowing a player to compete against a computer-controlled dealer.

## Features

- Random card dealing.
- Player can choose to hit or stand.
- Automatic Ace value adjustment (11 to 1) to prevent going over 21 where possible.
- Dealer automatically draws cards until reaching a score of at least 17.
- Automatic score calculation.
- Winner determination, including busts and ties.
- Input validation for player decisions.

## Technologies Used

- Python 3
- Random module

## Getting Started

### Prerequisites

Make sure Python 3 is installed on your computer.

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/salamibenbolu-ui/python-blackjack-game..git
   ```

2. Navigate into the project directory:

   ```bash
   cd python-blackjack-game.
   ```

3. Run the game:

   ```bash
   python Black_jack_game.py
   ```

## How to Play

1. The player and dealer are each dealt two cards.
2. One of the dealer's cards remains hidden during the player's turn.
3. Choose **HIT** to receive another card.
4. Choose **STAND** to keep your current cards.
5. Going over 21 results in a bust.
6. After the player stands, the dealer plays according to the game's rules.
7. The game compares both scores to determine the winner.
